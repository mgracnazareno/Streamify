# StreamUI — Online Streaming UI Concept

A modern, responsive front-end interface for an online streaming platform built as part of a UI/UX Design course.

Live Demo: https://online-streaming-app.netlify.app/

---

## Project Overview

This project focuses strictly on front-end UI/UX architecture, design systems, layout structure, and navigation. It demonstrates how to leverage Material UI (MUI) to create a cohesive design palette, typography hierarchy, and fully responsive layouts across various viewports.

Note: This repository represents a visual interface prototype. It intentionally does not contain backend architecture, database integration, or dynamic data fetching.

---

## Key UI/UX Features

- Component Design System: Implementation of modular, reusable Material UI components (Cards, Buttons, AppBars, Typography).
- Multi-Page Navigation: Seamless client-side routing via React Router.
- Visual Hierarchy & Layout: Consistent spacing, color palettes, grid alignment, and typography scales using MUI styling abstractions.
- Responsive Web Design: Fluid layouts optimized for mobile, tablet, and desktop displays.

---

## Tech Stack

- Framework: React 18
- Build Tool: Vite
- UI Framework: Material UI (MUI) v5
- Routing: React Router v6
- Styling: Emotion / MUI System Engine
